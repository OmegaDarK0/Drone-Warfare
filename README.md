## 1. About​
**Drone Warfare** is a 2D shooting game developed in C. The player
must face infinite waves of enemy drones. The main objective is to
survive as long as possible to achieve the best score. The score is
calculated based on the number of drones destroyed, their type, and
the selected difficulty. The project focuses on a minimalist and
dynamic gameplay, without any narrative context.​
​
​
## 2. Features​
* **Adjustable Difficulty Levels**: Choose from **4 game levels** and
**5 difficulties** (Easy, Medium, Harder, Hard, Insane).​
* **Infinite Enemy Waves**: Difficulty progressively increases with
faster and more numerous waves as the level progresses.​
* **Screen Resolution Adaptation**: The game is **adaptable to all
screen resolutions**, though it is **optimized and preferable for a
16:9 resolution**.​
* **Variety of Drones**: Face **4 different types of drones** with
unique characteristics:​
  * Drone​
  * Explosive Drone​
  * Nova Drone​
  * Hunter Drone​
* **Intuitive Controls**: Dive straight into the action with a simple
and efficient control scheme, including support for **AZERTY** and**QWERTY** keyboards.​
​
​
## 3. Installation and Compilation​
The project is compatible with **Windows** and **Linux** operating
systems.​
​
### Prerequisites​
* The **GCC** compiler.​
* The `make` command must be available.​
​
### Installation Steps​
1. Clone the Git repository or download the project source code.​
2. Compile the project by running the `make` command from the
repository root.​
​
### Launching the Game​
* **On Windows**: Execute the `run.bat` file.​
* **On Linux**: Execute the `run.sh` script. If the script is not
executable, grant it the necessary permissions with the command `chmod
+x run.sh`.​
​
​
## 4. Gameplay Instructions​
### Controls​
* **Movement**: Use the **W, A, S, D** keys (QWERTY) or **Z, Q, S, D**
keys (AZERTY).​
* **Aim and Shoot**: The player aims with the mouse cursor and shoots
by clicking.​
* **Pause**: Press the **PAUSE** key.​
* **Quit**: Press the **ESC** key.​
